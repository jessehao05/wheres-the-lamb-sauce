# where's the lamb saunce

- Ex. You want to know where you can get beef (ingredient) or vitamin C (nutrient)
- NetNutrition exists, but you would have to click on every dining hall and open each tab to see what the food and macros are
- Search feature that filters only the options with your desired ingredients/nutrients

## Dining Info

https://netnutrition.cbord.com/nn-prod/vucampusdining

## Core Features

## Display menus 

Like netnutrition, but with a more intuitive user interface. 

### Search whole day vs. search currently

Whole Day: 
- "Today, what dining halls will have beef?"

Currently:
- "What dining halls right now are open and have beef?"


### Search by ingredient in a dish
- Find dining halls with a certain ingredient
- Ex. beef, chicken, rice, pineapple

### Search by nutrient
- Find dining halls with dishes with certain nutrients
- Show how much of that nutrient for each dish
- Ex. vitamin C, zinc, iron

### Search by one vs. many ingredients/nutrients
- "What dining halls have dishes with zinc and dishes with vitamin C?"

## App Flow

At the start of each day, pull data from NetNutrition. 

## User Flow

Select whole day or current -> select ingredient or nutrient -> search -> see results
